DOCTOR HUB LAUNCHER

Purpose:
A tiny static launcher for mobile Home Screen installation.
It uses the approved Doctor Hub icon and redirects to the permanent LIVE Doctor Hub.

Files:
- index.html
- manifest.webmanifest
- apple-touch-icon.png
- icon-192.png
- icon-512.png

Important:
These files must be hosted together on a normal HTTPS static website.
Do not host the launcher as another Google Apps Script web app, because that can reproduce the icon issue already observed.
